## 📌 About

A simple **Light/Dark Theme Changer** made using HTML, CSS and JavaScript.

Click the button to switch between **Light Mode ☀️** and **Dark Mode 🌙**.

---

## ✨ Features

* 🌞 Light Mode
* 🌙 Dark Mode
* 🔄 One-click theme change
* 🎨 Smooth transition
* 📱 Simple responsive design

---

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Click the button and switch the theme. 🌗
